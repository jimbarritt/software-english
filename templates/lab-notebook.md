# Lab Notebook structure: a local reference cache for Software English

## Canonical sources

This file is a cache. It does not replace the canonical sources.

- Colin Purrington, "Maintaining a laboratory notebook": https://colinpurrington.com/tips/lab-notebooks/
- Rice University lab notebook guidelines: http://www.owlnet.rice.edu/~bios311/bios311/nbguidelines.html
- Bellevue College Lab Notebook Guidelines (PDF): https://www.bellevuecollege.edu/wp-content/uploads/sites/140/2014/06/Lab-Notebook-Guidelines.pdf

Independent guides converge on the same core rules. No single ISO or
ASTM standard exists for a general lab notebook. Treat this as
convergent practice, not a formal standard.

## Required structure

- The first pages hold a table of contents: an entry name and its page
  number.
- Pages hold a fixed number, assigned in advance. No page is removed.
- Each entry opens with a date and states its own purpose.
- Each entry names the experiment or task it belongs to.

## Hard rules

- No entry is erased.
- No correction fluid is used.
- An error is struck through with one line, so the original text stays
  legible. The correction goes beside it, not over it.

## Common variants

- A bound paper notebook and an electronic lab notebook (ELN) both
  follow the same core rules.
- A patent context adds a signature and a witness signature to each
  entry.
